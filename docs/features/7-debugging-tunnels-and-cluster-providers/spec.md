# Debugging, Local Tunnel, and Cluster Onboarding

These are delivery requirements, not a claim that the current implementation has passed acceptance.

- **M7-F1–F4:** Debug Attach connects an adapter for the actual project, Pod and container, language, process, port, and path. Cover .NET, Go, Java, Node.js, Python, and reachable legacy branches in the baseline. Support real breakpoints, resume and pause, stepping, stack traces, variables, and termination. Launch also includes build and push, debug resources, readiness, and actual startup. Remove Debug and explicitly enabled cleanup are limited to this run's resources. Generating configuration, showing DAP controls, or forwarding a port alone does not count.
- **M7-F5/F8:** Local Tunnel uses server-side Telepresence for connect, intercept, status, leave or quit, and recovery. Disclose traffic changes, possible agent injection, and their impact. Users prepare the client, Traffic Manager, daemon, and permissions. Do not install or escalate privileges implicitly, or substitute ordinary port forwarding.
- **M7-F6/F7/F9:** Connect Create/Add Cluster for reachable providers, including AKS. Identify the account, subscription, resources, costs, progress, and kubeconfig merge. Do not install a VS Code extension or switch accounts implicitly. Minikube offers Start, Stop, and Status only on applicable nodes, with no cluster creation wizard. Provider capabilities and dependencies must actually work. Cancellation does not delete cloud resources or guarantee traffic restoration. Keep unknown results marked as unknown.
