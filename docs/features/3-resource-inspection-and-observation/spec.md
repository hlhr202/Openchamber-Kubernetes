# Resource Reads and Observation

- **M3-F1/F8:** Load returns the named object's document. Get, Describe, Cluster Info, and Explain retain their respective outputs. An explicit Refresh can read a newer version of the same UID. It does not follow a same-named replacement, replace write confirmation, or overwrite a draft. Check the original target and cursor for each chunk. Distinguish an expired read, denied access, a missing object, and a budget overrun.
- **M3-F2:** Read ConfigMap or Secret content only when a key is selected. Viewing a Secret does not require an extra confirmation. Distinguish empty values, absent keys, non-text values, and decoding failures without changing the meaning of the original bytes.
- **M3-F3/F4/F7:** Pod and Job logs identify the actual Pod and container. Support the baseline log options, Follow, search and filtering, line wrapping, and explicit copying. Do not add a separate previous-log entry point. Use bounded in-memory snapshots or streams. Distinguish disconnects, truncation, and terminal states; do not mix separate container runs. A log-only terminal consumes read-only output without starting a PTY or shell.
- **M3-F5/F6:** Namespace events preserve counts, order, and expiry state. Branch or object Watch and Follow share bounded tasks starting from a valid list version. Coalesce updates and manage cancellation and deadlines per consumer. Stopping an observation does not trigger a write. Do not watch every branch indiscriminately.
