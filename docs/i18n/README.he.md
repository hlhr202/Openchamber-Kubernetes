## התקנה

לאחר פרסום קובצי ההרחבה שנבנו מראש בענף ברירת המחדל של המאגר:

1. ב־OpenChamber פתחו את **הגדרות ← הרחבות**.
2. הדביקו את כתובת המאגר בשדה **תיקייה, ZIP או כתובת URL** ולחצו על **הוספה**:

   ```text
   https://github.com/hlhr202/Openchamber-Kubernetes
   ```

3. בדקו ואשרו את ההרשאה המבוקשת לשירות המקומי, ואז פתחו את **Kubernetes** מסרגל ההרחבות.

אין צורך בבנייה מקומית או בהתקנת תלויות JavaScript. כל עוד המאגר פרטי, ל־OpenChamber Server צריכים כבר להיות פרטי אימות של Git שמאפשרים גישת קריאה דרך HTTPS. כניסה ל־GitHub בדפדפן אינה מעניקה לשרת את פרטי האימות האלה.

ל[גרסה המועמדת שנבדקה ב־Docker](../status.md) יש גם קובץ ZIP שנבנה מראש להתקנה ידנית. התקנה מכתובת Git טרם אומתה.

## דרישות מקדימות

- **OpenChamber 2.5.1**, גרסת היעד של ההרחבה.
- קובץ **kubeconfig** תקין ונגיש למשתמש במערכת ההפעלה שמריץ את OpenChamber Server, לצד גישת רשת ל־API של Kubernetes והרשאות לפעולות הרצויות.
- **`kubectl`** צריך להיות זמין בשרת. פעולות שקוראות ל־Helm CLI דורשות **Helm**. אם ה־kubeconfig משתמש בכלי עזר חיצוני לקבלת פרטי אימות, גם הכלי הזה חייב להיות זמין בשרת. ההרחבה אינה מתקינה את הכלים האלה.

## תכונות

- מעבר בין הקשרים ומרחבי שמות ב־Kubernetes ועיון בעומסי עבודה, בשירותים ובמשאבים מותאמים בעץ המשאבים.
- עיון במניפסטים של משאבים, קריאת יומני Pod והצגת אירועים במרחב שמות.
- סקירת שינויים במניפסטים והחלתם באופן מפורש על היעד שנבחר.
- פתיחת מסוף בקונטיינר שנבחר או הגדרת העברת יציאות.
- עיון במאגרים, בחבילות (charts), במהדורות ובהיסטוריית גרסאות של Helm.

## מה המחבר בדק

המחבר בדק בעצמו רק ארבעה תרחישים: הרחבת רשימות בעץ המשאבים, צפייה בפרטי משאבים, שימוש במסוף של קונטיינר והעברת יציאות. אם נתקלתם בבעיה או שיש לכם שאלה על תרחיש אחר, אתם מוזמנים [לפתוח פנייה ב־GitHub](https://github.com/hlhr202/Openchamber-Kubernetes/issues).

## פרטיות

- ההרחבה אינה שולחת למפתחים נתוני טלמטריה או ניתוח. היא משתמשת ב־kubeconfig שבשרת כדי להתחבר ל־API המוגדר של Kubernetes עם ההרשאות שכבר יש לכם.
- נתוני משאבים שאוחזרו, יומנים, פלט מסוף וטיוטות שלא נשמרו נשארים בזיכרון ואינם נכתבים לדיסק. ההרחבה שומרת העדפות שאינן רגישות, כמו בחירת מקורות kubeconfig, אך לא את תוכן הקבצים. שמירה או ייצוא מפורשים הם פעולות נפרדות.
- ערכים של אובייקטי Secret מוצגים רק לפי בקשה ובכפוף להרשאות שלכם ב־Kubernetes. נתוני האשכול אינם נשלחים אוטומטית לצ׳אט או לספק המודל.

הצהרה זו חלה על ההרחבה בלבד, ולא על OpenChamber, על Kubernetes או על הכלים והשירותים החיצוניים שבהם אתם משתמשים.
